# SURGE Mark.2 UART プロトコル — v0.22 → v0.23 差分

**日付**: 2026-10-12
**状態**: STM32 側・Pi 側とも実装済み・ビルド確認済み。**未書き込み、実機での動作検証は未了** (MD は変更なし)

ワイヤ形式 (LEN・オフセット) は変わらない。変わるのは調整パラメータの持ち方。

1. **調整パラメータの既定値をファームに持たない。** `control_params.h` の表の「既定値」列は「上位が送るまでの仮置き」になり、
   各範囲の下限 (= 何もしない値) にした。ステアのリンクの換算だけは恒等の 1・0。値の出どころは上位の `vehicle.toml` のみ。
   上位は全項目を送って `CONFIG_ACK.applied` で確かめるまで ARM を通さない (io_node の `_arm_block_reason`)。
2. **車速PIのゲインを調整パラメータにした。** `param_id` `0x0030` = `speed_kp` [N·m/(m/s)]、`0x0031` = `speed_ki`
   [N·m/(m/s)/s] (範囲 0〜2・0〜10)。以前は `DRIVE_SPEED_KP`/`KI` (0.3・0.6) の固定値で、上位の `[dynamics]` に同じ値を
   手で持っていた。`Drive_SetParams()` が毎周期 `speed_pid` へ写す。
3. **TC・TV の ON/OFF (`0x0010`/`0x0020`) の起動直後の値を無効にした。** 上位が `vehicle.toml` `[control]` の
   `tc_enable`・`tv_enable` を接続のたびに送る。

**`protocol_version` は `0x0016` → `0x0017`。** 上位と一緒に入れ替えること。**上位を先に入れる** (古いファームは `0x0030`/`0x0031`
に `UNKNOWN_ID` を返し、上位は ARM を通さない)。
