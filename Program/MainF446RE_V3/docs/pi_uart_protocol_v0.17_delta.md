# SURGE Mark.2 UART プロトコル — v0.16 → v0.17 差分

**日付**: 2026-10-08
**状態**: STM32 側・Pi 側とも実装済み・ビルド確認済み。**STM32 は未書き込み、実機での動作検証は未了**

v0.16 (`pi_uart_protocol_v0.16_delta.md`) からの差分のみを記す。変わったのは TV (トルクベクタリング)
だけで、**ワイヤ形式 (LEN・オフセット) は同じ**。`CONFIG_SET`/`CONFIG_GET` の `param_id` の入れ替えと、
`TELEMETRY` (0x02) の1項目の意味が変わる。

---

## 0. 要約

1. **TV をヨーレートの PI から、後輪左右の荷重に比例した配分へ置き換えた** (§1)。フィードフォワード
   だけで、規範モデル・積分・不感帯は無い。
2. **`param_id` `0x0021`〜`0x0029` を廃止** (`RAS_CONFIG_UNKNOWN_PARAM` を返す)、**`0x002B`・`0x002C` を
   新設** (§2)。`0x002A` (`tv_test_moment_nm`) は残る。
3. **`TELEMETRY` のオフセット 66 を `yaw_rate_target` → `tv_ratio` に置き換えた** (§3)。

**`protocol_version` は `0x0010` → `0x0011` に上がる。**

---

## 1. TV (`src/control/torque_vectoring.c`)

```
a_y   = 車速 × 実測ヨーレート                               (左旋回が正)
比率  = clamp(tv_load_gain_s2_per_m × a_y, ±tv_max_ratio)   (左右の荷重差 / 荷重和 の見積り)
ΔT    = T_right − T_left = 総駆動トルク × 比率
各輪  = (総駆動トルク ∓ ΔT) / 2 を、個別に ±DRIVE_MAX_TORQUE_NM へ収める
```

- 駆動 (総トルク > 0) では外輪が多くなる。車速PIの減速 (総トルク < 0) では外輪が多く制動する
  (旋回を戻す向き)。総トルクが 0 に近い定速の旋回では何もしない。
- 全開で外輪が上限に当たっても、内輪は荷重の比どおりのまま (外輪が出せない分を内輪へ載せない)。
  v0.16 の「左右差を保ったままもう片方を下げる」配分 (`AllocateTorque`) はやめた。
- TC はその後段で各輪を絞るだけ。TV は状態を持たないので、v0.16 の
  `TorqueVectoring_ReportApplied()` (積分の巻き戻し) は無くなった。
- IMU が使えない間 (ヨーレートが舵角からの幾何計算になる間)・制動モード・停車中は左右差 0。
  v0.16 の「0.30m/s 未満では介入しない」は無い (横加速度が小さいので比率も小さい)。
- `tv_test_moment_nm` が 0 以外の間は、配分を止めてそのヨーモーメントだけを出す (v0.16 と同じ。
  上限は表の範囲 ±0.2Nm)。

### やめた理由 (2026-10-08 の定常円旋回の記録から)

- 規範ヨーレートに実機の同定結果 (舵の効き) を入れていたので、偏差が最初からほぼ 0
  (標準偏差 0.086rad/s、半分の時間は不感帯 0.05rad/s の中)。要求ヨーモーメントは平均 0.004Nm。
- ヨーモーメント → ヨーレートの効きが小さい (0.1Nm → 0.056rad/s)。比例ゲイン 0.08 との積 =
  ループゲインは約 0.05 で、1 にするゲインでは偏差のノイズだけで上限に張り付く。
- 上限 0.15Nm で動かせる定常のヨーレートは舵角 約1° ぶん。舵は上位が直接指令でき、30° まで切れる。
- 回り過ぎの修正は内輪へトルクを足す向きになる。内輪は荷重が抜けて空転しており、TC が絞って
  打ち消した (左右差が要求と逆向きになった瞬間もあった)。

## 2. `CONFIG_SET` / `CONFIG_GET`

名前・`param_id`・既定値・範囲の唯一の定義は `src/control/control_params.h` の表。

| `param_id` | 名前 | 既定値 | 範囲 | 内容 |
|---|---|---|---|---|
| `0x0021`〜`0x0029` | (欠番) | — | — | v0.16 の TV (ヨーレート PI) の調整パラメータ。**廃止**。`result = 1` (不明な `param_id`) を返す |
| `0x002A` | `tv_test_moment_nm` | 0.0 | -0.2〜0.2 | 同定用 (v0.16 と同じ) |
| `0x002B` | `tv_load_gain_s2_per_m` | 0.045 | 0〜0.5 | 配分の比率 = これ × 横加速度 [1/(m/s²)]。0 で TV なし |
| `0x002C` | `tv_max_ratio` | 0.5 | 0〜1.0 | 比率の上限。1 で内輪のトルクが 0 |

`tv_load_gain_s2_per_m` の理論値は 2 × 重心高 × (後軸のロール分担) / (トレッド × g)。
既定値 0.045 は上位側の車両モデルの机上値 (`lateral_transfer` 0.13 × 質量 2.0kg ÷ 後輪1つの
静止荷重 5.75N) で、**実機では未調整**。

v0.16 の上位 (0x0021〜0x0029 を送る) とつなぐと、それらに `result = 1` を返すだけで走行はできる
(TV は既定値で動く)。

## 3. `TELEMETRY` (0x02)

LEN は 84 のまま。

| オフセット | 型 | 名前 | スケール | 内容 |
|---|---|---|---|---|
| 66 | i16 | `tv_ratio` | 0.0001 | TV の配分の比率 (左旋回で正 = 右輪が多い。上限で丸めた後)。**v0.16 はここに `yaw_rate_target` (0.001 rad/s)** |
| 68 | i16 | `tv_moment_nm` | 0.0001 N·m | TV が要求した左右トルク差をヨーモーメントに換算した値 (左旋回が正)。位置・スケールは v0.16 と同じ |

`flags` bit6 (`TV_ACTIVE`) は従来どおり「要求した左右差が 0.002Nm を超えている」。

## 4. 関連する変更

- `Drive_GetTargetYawRate()`・`Drive_GetYawMomentTorque()` を削除、`Drive_GetTvRatio()` を追加。
- `host/host_sim.c` の出力列 `OUT_YAW_TARGET` は、ファームの規範ヨーレートではなく車両モデルの
  「舵で決まる定常のヨーレート」を出す (列の並びは同じで `HOST_SIM_ABI` は 3 のまま。v0.16 以前の
  `src/control` とも組める)。
- 上位側 `tools/ctrl_tune/tests` に TV の約束 (外輪が多い・比率が式どおり・総和を変えない・
  減速で逆向き・直進とゲイン 0 で差なし) を追加した。
